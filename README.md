## 💻 Algoritmos e Estrutura de Dados III (C04) - Inatel

### 📌 Sobre o Repositório

Este repositório contém todos os códigos, listas de exercícios e trabalhos práticos desenvolvidos durante a disciplina **C04 - Algoritmos e Estrutura de Dados III**, cursada no **Instituto Nacional de Telecomunicações (Inatel)**.

O objetivo da disciplina é o estudo da análise de complexidade de algoritmos e o projeto de algoritmos avançados (como força bruta, estratégia gulosa, divisão e conquista e programação dinâmica), além do estudo profundo de grafos, algoritmos geométricos e estruturas de dados do tipo árvore.

### 💡 Como Executar

Para compilar e rodar os códigos deste repositório:

1. Clone o repositório:
   `git clone https://github.com/carolferreirauai/c04_algoritmos_e_estrutura_de_dados_III.git`

2. Navegue até a pasta do arquivo desejado via terminal.

3. Compile o código:
   `g++ nome-do-arquivo.cpp -o executavel`

4. Execute o programa:
   `./executavel` (Linux/Mac) ou `executavel.exe` (Windows).
